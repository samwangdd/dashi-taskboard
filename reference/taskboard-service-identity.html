Taskboard 服务身份诊断卡

不要先问“我在哪个 workspace”；先分别确认客户端终点、端口所有者、服务代码根目录和数据文件。

四个身份问题

1. 客户端打到哪里？
echo "${TASKBOARD_URL:-http://127.0.0.1:47823}"
command -v taskctl
2. 谁占着端口？
lsof -nP -iTCP:47823 -sTCP:LISTEN
3. 服务从哪里启动？
lsof -a -p <PID> -d cwd -Fn
curl -s http://127.0.0.1:47823/api/meta
4. 数据来自哪里？
lsof -p <PID> | grep taskboard.sqlite

并行启动两个 checkout

# checkout A
TASKBOARD_WEB_PORT=5173 TASKBOARD_PORT=47823 TASKBOARD_DATA_DIR=.data npm run dev

# checkout B
TASKBOARD_WEB_PORT=5174 TASKBOARD_PORT=47901 TASKBOARD_DATA_DIR=.data npm run dev

两个 checkout 可以各用自己的相对 .data；真正必须不同的是后端端口和 Vite 端口。调用 B 时还要设置 TASKBOARD_URL=http://127.0.0.1:47901。

判断口诀

目录决定默认文件；环境变量决定端口；URL 决定客户端；PID 决定当前事实。
